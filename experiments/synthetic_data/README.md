# Synthetic trained-head availability study

Supplementary results in an OFDMA factory-scenario proxy domain; these do not reproduce the measured LatentWave tasks, and the measured-data experiment remains primary evidence. Each report is generated only from validation selection artifacts until a separate review approval is recorded.

| Family | Task proxy | Status |
|---|---|---|
| Antenna channels | NR positioning / factory localization | Reported per task when selection artifacts are reviewed |
| Antenna channels | Interference / jammer presence | Reported per task when selection artifacts are reviewed |
| Antenna channels | Jamming / jammer mode | Reported per task when selection artifacts are reviewed |
| Temporal patches | NR positioning / factory localization | Reported per task when selection artifacts are reviewed |
| Temporal patches | Interference / jammer presence | Reported per task when selection artifacts are reviewed |
| Temporal patches | Jamming / jammer mode | Reported per task when selection artifacts are reviewed |

Profiles, generator code, and immutable master/manifests are versioned under `configs/synthetic_trained_heads/`, `src/synthetic_study/`, and `data/synthetic_trained_heads/` (generated data are ignored by Git).

The locked formal sample count and pilot-projected test-precision shortfalls are documented in [sample_count_precision.md](sample_count_precision.md). Test execution remains gated on manual review of the validation-only selection packets.
