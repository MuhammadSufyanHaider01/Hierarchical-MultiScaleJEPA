# Interference (OFDMA Jammer-Presence Proxy) — condition-specific-head diagnostic

This validation-only diagnostic asks whether the primary trend depends on training heads only at each sweep’s full-information condition. It uses paired realizations and shared split IDs; it is synthetic-domain evidence, not a recreation of measured LatentWave data.


Strict-best-layer companion files (`best_layer_diagnostic.*`, `best_layer_comparison.png/.pdf`) use the same synthetic exit-selection split and fixed-exit metrics. They report exact argbest layers separately from the official 5% selector; labels show the strict argbest layer used for each plotted point. These are synthetic-domain selection diagnostics, not test results.


Figure policy: all comparison plots show only the two condition-specific-head curves (LatentWave + EE and proposed hierarchical). Full-information-head values remain in the paired diagnostic tables for audit but are intentionally omitted from these figures.
