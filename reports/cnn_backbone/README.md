# CNN backbone reports

This directory contains report packets for CNN-backbone experiments. It is
separate from `reports/masking_study/`, which contains the established ViT
masking-study results.

The initial packet will be written to
`multi_block_n6/cnn_p0_vs_cnn_p2/` after both CNN methods complete their
pretraining, six-task downstream evaluation, and inference benchmarking.
