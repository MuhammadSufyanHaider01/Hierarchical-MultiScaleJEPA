# Residual Dynamic Fusion V2 — seven-head-seed study

Current EE and Residual Dynamic Fusion V2 are compared for P0/P2 using head seeds 0–6. Validation selects each exit; test evaluates it afterward. Aggregate tables report mean, sample SD, min/max, per-seed values, and selected-exit frequencies. Positive direction-aware gains favor V2; for positioning they are error reductions.

## P0/P2 four-approach comparison

`p0_p2_six_task_fusion_comparison.png` and `.pdf` compare Current EE and Residual Dynamic Fusion V2 at fixed exits for P0 (no multiscale) and P2 (multiscale). Each panel covers one downstream task; solid lines show the seven-seed mean without deviation bars.
