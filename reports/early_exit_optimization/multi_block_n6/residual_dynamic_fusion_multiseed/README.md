# Residual Dynamic Fusion V2 — seven-head-seed study

Current EE and Residual Dynamic Fusion V2 are compared for P0, P1, P2, and P2-Reverse using head seeds 0–6. Validation selects each exit; test evaluates it afterward. Aggregate tables report mean, sample SD, min/max, per-seed values, and selected-exit frequencies. Positive direction-aware gains favor V2; for positioning they are error reductions.
