# Single-GELU Fusion — seven-head-seed study

Current EE and Single-GELU Fusion are compared for P0 and P2 using head seeds 0–6. Validation selects each exit and held-out test evaluates it afterward. Aggregate tables report mean, min/max, per-seed values, and selected-exit frequencies. Figures draw mean lines without variance/error bars; all plotted lines are solid and marker shapes distinguish methods in the combined figure. Sample variance and sample SD are stored separately in the `*_variance_sd.csv` files. Positive direction-aware gains favor Single-GELU Fusion; for positioning they are error reductions.
